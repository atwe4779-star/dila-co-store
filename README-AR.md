# تحديث متجر DILA CO — الطلب عبر واتساب

## التحديثات
- إضافة رقم واتساب المتجر: 966553868373.
- عرض مدة التوصيل المتوقعة في أسفل الصفحة: خلال 7 أيام.
- تحويل إتمام الطلب إلى واتساب برسالة جاهزة تتضمن المنتجات والكميات والإجمالي وبيانات العميل.
- تحديث المنتجات الثلاثة وأسعارها المبدئية:
  - سلة مهملات السيارة: 39.90 ر.س
  - شبكة تخزين السيارة: 34.90 ر.س، بخمسة مقاسات متساوية السعر
  - منظّم فجوات المقاعد (قطعتان): 29.90 ر.س

## رفع التحديث
1. فك ضغط الملف.
2. ارفع محتويات الحزمة إلى مستودع GitHub الخاص بالمتجر.
3. استبدل الملفات التي تحمل الأسماء نفسها.
4. ارفع صور المنتجات داخل `assets/products/` بالأسماء `product-1.jpg` و`product-2.jpg` و`product-3.jpg`.
5. انتظر انتهاء GitHub Pages من النشر، ثم اختبر المتجر على delaco.store.

## تنبيهات
- الأسعار المعروضة هي أسعار بيع مقترحة وليست مؤكدة من صاحب المتجر؛ عدّلها قبل النشر إذا لزم.
- مدة التوصيل المعروضة «خلال 7 أيام» كما طلب صاحب المتجر، ويُفضّل التأكد من قدرة التوريد على الالتزام بها.
- لا توجد بوابة دفع إلكترونية مدمجة؛ يتم الاتفاق على طريقة الدفع عبر واتساب.
